# PCLMS bug 修法

## 背景
修正 PCLMS 更新失敗卻未報錯的問題。

## 決策
透過驗證 JDBC `executeUpdate` 的回傳值（應大於 0），若失敗則顯式調用 `rollback`。

## 影響
在不變更資料庫 Schema 的前提下，確保資料一致性並能正確捕捉錯誤。
