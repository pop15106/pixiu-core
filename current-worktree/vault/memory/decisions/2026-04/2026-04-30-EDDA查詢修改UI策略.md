# eDDA 3.4 查詢修改 UI 策略修正

## 決策

「查詢修改」不應以彈窗底部動作按鈕作為主要切換方式，應改由「2 申請類別」欄位本身提供中文選項。

## 規則

- 審查駁回(2)、授權駁回(5)：可全欄位修改。
- 授權通過(4)：可選 `修改授權` 或 `終止授權`。
- `修改授權`：僅付款限額可改。
- `終止授權`：全欄位唯讀。
- 畫面顯示中文，前後端傳輸仍可使用代碼。

## 來源

使用者於 2026-04-30 實測回饋 Claude 昨日改動後提出。

## 補充釐清

本次 3.4 修改的最小目標是讓授權通過(4) 可修改付款限額；同時不得破壞既有狀態 2/5 的修改功能。若修正方案會讓 2/5 進入全唯讀，視為回歸問題。
