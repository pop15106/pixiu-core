# Agent Learning 區

這一區是給「過去怎麼解決問題、前輩怎麼處理、什麼情境下哪種做法有效」這類經驗沉澱用的。

目的不是取代 `recap` 或 `decision`，而是補中間那層：

- `recap` 記事件流
- `decision` 記已採納規則
- `agent-learning` 記可重用經驗與策略

## 子區說明

- `observations/`
  - 單次經驗整理後的結構化觀察
- `instincts/`
  - 多次出現後可提煉成的短規則
- `promote-candidates/`
  - 準備升級成 `decision` / `skill` / `sop` 的候選內容

## 你之後怎麼用

最簡單的方式是直接把材料丟給我，例如：

- 這次問題最後怎麼解
- 前輩怎麼教你查
- 哪張圖、哪段對話、哪份文件最有用
- 下次遇到類似問題你會先做什麼

我會先幫你整理，再決定要寫成：

- `observation`
- `instinct`
- 或升格成 `decision`

## 與第二大腦關係

這區也是 Markdown source of truth，所以 second-brain 會吃到。
但仍然建議維持：

1. 先人工整理
2. 再寫入這區
3. 再同步 second-brain

這樣向量檢索吸收到的是整理過的經驗，而不是原始雜訊。
