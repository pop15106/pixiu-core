# Observations

Observation 適合放：

- 某次問題最後怎麼破
- 哪個查法有效
- 哪個線索其實是誤導
- 前輩教的判斷方式
- 某個系統的實務眉角

先寫 observation，不代表它一定是真理。
它比較像「已整理的經驗卡片」。
