# Instincts

Instinct 適合放：

- 反覆出現的查法
- 某類問題的第一優先切入點
- 常見誤判與避免方式
- 某系統特有的工作直覺

Instinct 不是正式 decision。
它是高重複率、但仍保留邊界與信心值的規則。
