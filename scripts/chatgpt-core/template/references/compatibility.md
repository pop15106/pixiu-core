# ChatGPT 相容性與執行界線

| 母體內容 | 本包處理 | 驗證界線 |
| --- | --- | --- |
| Skill 與治理文件 | 保存版本快照，嵌入入口改用 SKILL.reference.md，按需讀取 | 讀取成功才回報已載入 |
| .agent/workflows/*.md | 保存原文與目錄，由主 Skill 路由流程步驟 | 本包未註冊獨立原生 Workflow 或斜線命令 |
| CR／Lifecycle／風險覆核 | 可於對話內執行指令流程；保留 runtime 原碼 | 對話內分析、正式帳本與程式 Gate 分別回報 |
| Node 路由與 CR 程式 | 在提供 Node／檔案執行權限的環境可用 | 執行時核對目標工作目錄及原始證據 |
| DevSpace／GitHub／文件工具 | 使用目前已連接的工具 | 安裝 Skill 不等於已連接或部署服務 |
| /go、需求、報修與覆核 | 對應 Skill 指令與相依參考資料 | 文件格式、瀏覽器或測試工具缺失時標示未執行 |
| CRD、Pro析、X析 | 保留使用者明確選用的純文字分支 | 指令流程不切換官方模型或推理強度 |
| Hooks、排程、背景執行與主動推播 | 僅保留相關規範 | 需要宿主或連接工具的實際服務支援 |
| 私人記憶、.cr、現行工作帳本、憑證 | 保持在原環境 | 需按任務與權限回讀，不帶入可重用 Skill |
| 第三方大型技能庫與未追蹤草稿 | 不併入核心快照 | 明確需要時回到母體或來源按需讀取 |

來源快照包含母體治理、路由、一般一級技能、Workflow、命令及 Router／CR runtime。其他部署腳本、外部套件與執行服務依實際工作機確認。必要檔案未提供時清楚指出依賴，不以較弱驗證替代。

每次版本更新先確認工作機與遠端的 commit 一致，再更新 snapshot.json。雜湊只核對包內檔案是否改變，不代表外部獨立審查或不可偽造身分簽章。

母體內的技能規格保留原文，只有最外層入口使用 SKILL.md，避免宿主將參考規格誤判為多個安裝項目。snapshot.json 記錄原始路徑與儲存路徑；分段讀取接受原始路徑，materialize-source.cjs 可在新暫存目錄還原完整原始檔名與位元組。
