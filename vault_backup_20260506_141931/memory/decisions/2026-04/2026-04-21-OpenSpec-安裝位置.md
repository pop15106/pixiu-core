# OpenSpec 安裝位置

## 背景
導入 OpenSpec 時需決定 config 由誰管理。

## 決策
在母體建立 `openspec/templates/` 和 `registry.yaml`，子專案執行 register 腳本取得 config。

## 影響
config 更新只需改母體 template，所有已註冊專案重新 register 即可同步。
