# 母體 OpenSpec 初始化方式

## 背景
OpenSpec 標準做法是在專案跑 `openspec init`，但母體性質特殊。

## 決策
母體只放 templates/ 和 registry.yaml，不跑 openspec init，不產生 openspec/changes/。

## 影響
母體保持乾淨的配置 repo 性質，不引入 npm 依賴與功能開發產物。
