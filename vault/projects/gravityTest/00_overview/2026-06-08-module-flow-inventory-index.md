```mermaid
  FD["PCLMS_FD\nReact pages / API modules"] --> API["/APCLMS2-API\nbackend endpoints"]

  API --> Services["service / controller / REST layer"]
  Servlets --> LegacyLogic["servlet / model / common / components"]
  Services --> Libs["PCLMS_LIBS_new\nDAO / PO / shared domain"]
  LegacyLogic --> Libs
  Libs --> DB["Oracle / CLMS tables"]
  BK["PCLMS_BK_new\nCron / job / message / iog / send"] --> Libs
  BK --> External["Files / SE / SM / monitors / downstream exchange"]
  DB --> BK
```
