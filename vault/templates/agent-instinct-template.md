# Instinct -

## Trigger

什麼敘述或情境會觸發這條規則。

## First Move

第一步先查什麼、先排除什麼。

## Rationale

為什麼這樣切通常比較快。

## Boundaries

什麼情況不適用。

## Evidence Base

支撐這條規則的 observation / 真實案例。

## Promotion Rule

滿足什麼條件後，可以升格成 decision / SOP / skill。
