# Observation -

## Context

描述可被回查的情境、限制與觸發點。

## Action

記錄當時實際採取的行動，不要補寫未發生的步驟。

## Result

描述行動後的直接結果，可包含部分成功、失敗或副作用。

## Why It Happened

把可驗證事實與推論分開寫，避免把推論寫成既成事實。

## Recommendation

寫下下一次可重用的候選做法，保持在 observation 等級，不要直接升格成規則。

## Evidence

- repo 或 vault 相對路徑
- 關鍵段落、命令輸出或可回查證據
- 如有推論，標出它依附的證據

- verifier: manual / model / script
- result: pass / needs-review / reject
